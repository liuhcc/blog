大模型人工智能学习：项目计划

项目目标

以真实项目为载体学习大模型开发，而不是只停留在观看课程或调用 API。计划从 2026-08-24 开始，25 周内完成 3 个可展示项目；每个阶段都需要有可运行样例、清晰输入输出和复盘记录。

每周节奏

每周计划投入 27.5 小时：工作日安排新知识、跟敲、练习和纠错；周末用于项目深度开发、演示和复盘。每次学习前后各保留 15 分钟用于回顾与提交记录，视频学习控制在 40% 以内，编码、调试和复盘不少于 60%。

第 1-9 周：基础与模型能力

  • 第 1-2 周完成 Python 核心：文件处理、异常处理、面向对象和 HTTP 调用。
  • 第 3 周补齐算法与数据结构：复杂度、常用容器和针对性练习。
  • 第 4-5 周完成 Linux、Shell、Git、MySQL 与 CRUD API。
  • 第 6-8 周学习 NumPy、Pandas 和机器学习、深度学习必要原理。
  • 第 9 周跑通 BERT 分类与 FastAPI 推理接口，理解 tokenizer 和评估。

第 10-17 周：大模型应用核心

  • 第 10-12 周独立完成带引用的 RAG，并实现至少一个 MCP tool、server 或 client。
  • 第 13 周使用 Coze 或 Dify 搭建工作流，并通过 Python 调用，明确低代码平台的适用边界。
  • 第 14 周跑通 LoRA 或 QLoRA 示例，理解微调与 RAG 的选型边界。
  • 第 15-17 周完成 LangGraph 的状态、分支、重试、检查点、记忆与人机中断练习。

第 18-25 周：Agent 项目与交付

  • 第 18-20 周复现并改造点餐 Agent，串联 FastAPI、工具调用、向量检索和数据库。
  • 第 21-23 周复现并改造问数 Agent，完成受控 Text-to-SQL 与结果解释。
  • 第 24-25 周完成个人项目交付：认证、日志、追踪、评测集、异常处理、Docker 部署、README 和演示视频。

作品集与调整规则

  • 三个作品集分别聚焦企业知识库 RAG、垂直领域工具 Agent、数据问答或业务自动化 Agent。
  • 每周以计划工时与完成标准衡量完成度：90% 以上保持节奏；70%-89% 优先补齐未完成项；低于 70% 则收缩到 Python、后端、RAG、MCP、LangGraph 和项目主线。
  • 每次学习记录日期、计划与实际时长、完成内容、代码链接、阻塞问题和下一步；公开笔记只发布脱敏后的总结。
