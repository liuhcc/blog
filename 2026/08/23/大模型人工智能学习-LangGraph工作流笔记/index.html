三个基本组成

LangGraph 用状态保存流程上下文，用节点承载处理逻辑，用边描述执行顺序。条件边负责根据状态选择下一步，使路由规则从提示词文本中独立出来。

练习关注点

基础练习可以从数值计算和奇偶路由开始：定义状态、编写节点、配置条件边，再观察每一步状态如何变化。并行分支汇合时，要明确节点是否需要等待全部前序节点完成，避免同一节点因错误编排被重复执行。

工程化设计

  • 状态只保存必要且可序列化的数据。
  • 节点保持职责单一，模型调用、工具执行和结果整理分开。
  • 为失败、重试、超时和人工确认设计明确分支。
  • 使用检查点保存关键状态，让长任务可恢复、可审计。

与 Agent 项目的关系

LangGraph 是将 RAG、工具调用和业务规则编排为可靠应用的骨架。后续点餐和问数项目都可以用它表达路由、检索、生成、校验和最终答复。
