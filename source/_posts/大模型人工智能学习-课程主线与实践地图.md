## 学习范围

课程资料共分为 18 个阶段。前半段建立 Python、算法、数据库、数据分析、机器学习、深度学习和 NLP 基础；后半段进入 Agent、LangChain、MCP、Coze/Dify、微调、强化学习、多模态、LangGraph 和综合项目。

## 不平均投入时间

完整课程目录很宽，但项目主线不需要平均推进。优先级应当是：Python 与后端基础 -> NLP 与模型服务 -> RAG/MCP -> LangGraph -> Agent 项目交付。强化学习与多模态在主项目完成后，按业务需要再深入。

## 三条实践线

### 知识增强线

从文本切分、Embedding、向量检索开始，逐步加入重排序、引用和检索评测，最终形成一个可追溯的企业知识库 RAG。

### 智能体编排线

从工具定义与调用开始，学习 LangChain 和 MCP 的边界；再使用 LangGraph 组织状态、分支、重试、记忆和人工确认，保证复杂任务可控、可恢复。

### 业务交付线

课程中的智能体点餐和智能体问数项目提供了完整业务场景。学习时重点不是照搬业务，而是抽取通用能力：FastAPI 服务、工具调用、向量检索、数据库、权限、SQL 安全、日志和 Docker 部署。

## 笔记发布原则

博客只发布个人学习总结、实验结论和自行编写的示例，不转载课程视频、课件、完整源码或内部配置。每篇笔记固定回答五个问题：解决什么问题、采用什么方案、关键实现点、如何验证、下一步如何改进。
